# 📊 Excel Sales Dashboard Analysis
An interactive **Microsoft Excel Sales Dashboard** built to analyze sales performance using **Pivot Tables, Pivot Charts, Slicers, Excel Formulas, and Data Visualization**. This project enables users to explore sales trends, monitor employee performance, and evaluate target achievement across different cities.
---
## 📌 Project Overview
This dashboard transforms raw sales data into meaningful business insights through interactive visualizations. Users can filter data by city, compare sales executives, and monitor key performance indicators (KPIs) to support data-driven decision-making.
---
## 🎯 Objectives
- Analyze sales performance across multiple cities.
- Monitor individual sales executives.
- Measure target achievement percentages.
- Identify employees who are below target.
- Present business insights using interactive dashboards.
